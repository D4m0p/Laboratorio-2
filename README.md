# Laboratorio 2 - HTML5 y CSS3

Maquetación estructurada y presentación de datos tabulares con HTML5 y CSS.
Materia: Desarrollo Web - Grupo 1S3122 - Instructora: Irina Fong
Módulo II: Diseño Web con HTML5 y CSS3 - II Semestre 2026

## Contenido

- `Laboratorio #2 HTML5.pdf` - Enunciado del laboratorio
- `index.html` - Página de inicio con enlaces a todos los ejercicios
- `tabla1.html` - **Tabla #1**: informe de gastos de viaje con metadatos en el `<head>`,
  `<caption>` y celdas `<th>` con los atributos `id`, `axis` y `headers`
- `tabla2.html` + `Estilos/estilosTabla.css` - **Tabla #2**: tabla con hoja de estilos
  externa, estilo propio para las cabeceras `<th>` y las clases de fila `.modo1` y `.modo2`
- `ejemplo3_parrafos.html` + `Estilos/estilosParrafos.css` - **Ejemplo #3**: selector
  descendiente `p strong`
- `ejemplo4_navegacion.html` - **Ejemplo #4**: enlace externo seguro (`target="_blank"`,
  `rel="noopener"`), selectores de clase (`.card-seccion`, `.link-externo`) y de ID (`#footer-recurso`)
- `ejemplo5_secciones.php` - **Ejemplo #5**: estructura con etiquetas semánticas
  (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`);
  el año del pie de página se genera con PHP
- `validaciones.html` - Validación de formularios con HTML5 y las pseudoclases
  `:required:invalid` y `:required:valid`

## Temas

1. Configuración y metadatos del documento (`<head>`, `charset="UTF-8"`, `viewport`).
2. Elementos semánticos y estructurales de HTML5 (`<section>`, `<footer>`).
3. Tablas HTML (`<table>`, `<tr>`, `<th>`, `<td>`).
4. Hipervínculos y navegación (`<a>`, `href`, `target="_blank"`, `rel="noopener"`).
5. Selectores CSS: de etiqueta, de clase (`.clase`), de ID (`#id`), universal,
   descendiente y de hijo.

## Requisitos

- Un navegador web.
- PHP, solo para el Ejemplo #5.

## Cómo ejecutarlo

1. Abrir una terminal dentro de la carpeta del proyecto.
2. Levantar el servidor: `php -S localhost:8000`
3. Abrir en el navegador `http://localhost:8000/` y elegir el ejercicio.

Los archivos `.html` también se pueden abrir directamente en el navegador, sin servidor.
