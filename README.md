## Temas

1. Configuración y metadatos del documento (`<head>`, `charset="UTF-8"`, `viewport`).
2. Elementos semánticos y estructurales de HTML5 (`<section>`, `<footer>`).
3. Tablas HTML (`<table>`, `<tr>`, `<th>`, `<td>`).
4. Hipervínculos y navegación (`<a>`, `href`, `target="_blank"`, `rel="noopener"`).
5. Selectores CSS: de etiqueta, de clase (`.clase`), de ID (`#id`), universal,
   descendiente y de hijo.
